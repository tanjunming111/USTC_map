# 中国科学技术大学东校区三维地图

一个可离线打开的东校区地图，提供可旋转的校园沙盘、二维俯视和第一人称漫游。可以按类别浏览校园地点，也可以用楼名、楼号或道路名称搜索。

## 打开地图

双击 [index.html](index.html)，或将它拖入浏览器。请保留同目录下的 JavaScript 和 CSS 文件。打开地图无需安装依赖或启动服务器。第一人称漫游需要浏览器支持 WebGL，沙盘可在 WebGL 不可用时继续浏览。

## 操作说明

### 校园沙盘

- 鼠标拖动旋转，滚轮缩放，按住 `Shift` 拖动平移。触屏上单指拖动旋转，双指缩放或平移。
- 点击右侧的 `2D` 切换到二维俯视，点击 `3D` 返回立体沙盘。点击 `↺` 或在沙盘聚焦时按 `Home` 回到全景。
- 「全部」视图会按屏幕空间显示楼宇和地标标签。可按教学科研、行政办公、宿舍、道路等类别筛选。
- 搜索可用简称或楼号，例如「一教」「320#」「金寨路」。点击结果或地图标签查看详情并定位，按回车可定位到第一条搜索结果。
- 地点卡片会列出可用的楼号、楼层、模型高度和附近地点。附近距离为估算的直线距离，点击可切换地点。

### 第一人称漫游

点击顶栏的「第一人称漫游」。首次进入默认站在西门外，面向门楼。也可先在沙盘中选地点，再从它附近开始漫游。漫游时点击新的搜索结果，会直接移动到对应地点附近。

| 操作 | 按键或手势 |
| --- | --- |
| 前进、后退、左右移动 | `WASD` 或方向键 |
| 转头 | 鼠标拖动，或点击「锁定鼠标视角」后移动鼠标 |
| 释放鼠标 | `Esc` |
| 加速 | 按住空格并移动 |
| 垂直上升 | `Shift + W` 或 `Shift + ↑` |
| 垂直下降 | `Shift + S` 或 `Shift + ↓` |
| 自由下落 | 在空中轻按 `X`。松键后继续下落，触地后轻微回弹一次 |
| 触屏行走 | 按住左下角方向按钮，拖动画面转头 |

准星对准楼体时会显示楼名、楼号或模型编号。左上角小地图显示位置和朝向，校内路名可在交叉口的实体路牌上查看。可以经校门走到金寨路、黄山路、太湖路和宿松路的校园邻近路段，也可以在「道路」分类中直接选择这些道路。

搜索「地下通道」，选中「金寨路地下通道」后点击「从这里漫游」，即可从郭沫若路与勤奋路的十字路口向西下坡。通道可双向步行，另一端通往科学大道。

## 文件结构

| 文件 | 用途 |
| --- | --- |
| `index.html`、`style.css` | 页面和绿色界面主题 |
| `atlas.js` | 沙盘、俯视、地点搜索、分类和标签布局 |
| `walk.js` | 第一人称控制、碰撞、下落和小地图 |
| `campus-renderer.js` | 三维沙盘和第一人称的 WebGL 渲染 |
| `walk-mesh.js` | 共用的楼体、屋顶、看台、校门、绿化、铺装和水面网格 |
| `campus.js` | 校园地点、建筑样式、景观布置及通行范围 |
| `east-osm.js` | 从东区 GeoJSON 生成的离线数据 |
| `build-east-data.cjs` | 重新生成 `east-osm.js` 的脚本 |
| `assert/` | 一教南侧梧桐、校训石和郭沫若广场的建模参考照片 |

## 更新底图

只有重新生成底图时才需要 Node.js。脚本读取同级 `source/osm/` 下的 `ustc-east.geojson` 和 `ustc-campus-boundaries.geojson`，并写入项目目录下的 `east-osm.js`。

在项目目录运行以下命令。

```powershell
node build-east-data.cjs
```

生成后刷新地图即可。景观布置、地标说明或建筑外观的改动可直接在对应源码中编辑。

## 数据来源与精度

- 太湖路沿线的建筑轮廓基于本地底图，环资楼、礼堂、理化大楼、地空前沿研究中心及两座南侧校门的外观参照截图建模。局部体量、屋顶构件和步道为估算。校医院楼名按截图标注，底图旧称可用于搜索。 [校方楼名资料](https://www.ustc.edu.cn/info/1366/24816.htm)
- 校区边界、建筑轮廓和道路主要来自本地 OpenStreetMap 数据包。建筑高度依据可用的楼层记录或建筑类型估算。 [数据包说明](../source/README.md) · [© OpenStreetMap contributors（ODbL）](https://www.openstreetmap.org/copyright)
- 一教门廊、老北门和西大门、眼镜湖等场景参考校方公开的全景和校园资料。详情卡里的「东区 VR 实景」链接需要联网打开。 [中科大东区 VR](https://map.ustc.edu.cn/sj/e/index.html) · [校方校园地图](https://map.ustc.edu.cn/)
- 参考广西大学三维校园的分场景建模方式，将建筑入口、屋面、场地和绿化细节做进地图模型。 [广西大学三维校园建模文档](https://github.com/wcqqq1214/gxu-campus-3d/blob/main/docs/MODELING.md)
- 缺少实景资料的楼体按建筑类型细化窗格、阳台和屋面，细部尺寸为估算。部分岸线、绿化位置和校门连接段为示意。漫游范围覆盖东校区室外和周边道路。
